# config/

| File | What |
|---|---|
| `effects.json` | Your SC Haptics effects. On Linux, `~/sc_haptics/effects.json` links here; on Windows the installer copies it to `%USERPROFILE%\sc_haptics\effects.json`. **Updates never overwrite it.** The defaults are in `plugin/effects.default.json`. |
| `simhub/Star Citizen.simdef` | SimHub's game definition "Star Citizen" (24 fields). The installers copy it into SimHub and register it; the bridge packs exactly the fields of the registered file. |
